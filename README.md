# Manual de Marca — Solei

Recursos de identidad visual y manual de marca para **Solei**, marca de moda con estética de lujo contemporáneo.

## Contenido

| Archivo / Carpeta | Descripción |
|-------------------|-------------|
| `Manual de Marca — Solei.pdf` | Manual de marca completo en PDF |
| `moodboard-solei.html` | Moodboard interactivo de la marca |
| `solei-wordmark-black.png` | Wordmark en negro |
| `solei-wordmark-white.png` | Wordmark en blanco |
| `logo solei.png` | Logo principal |
| `Destacados IG/` | Íconos para destacados de Instagram |

### Destacados de Instagram

Íconos diseñados con referencias a marcas de lujo: Celine, Chanel, Dior, Miu Miu, Off White, Prada, YSL.

## Uso

- Consultar `Manual de Marca — Solei.pdf` para lineamientos completos de identidad visual.
- Abrir `moodboard-solei.html` en el navegador para explorar el universo estético de la marca.
